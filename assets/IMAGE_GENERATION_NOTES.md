# Image Generation / Reconstruction Notes

The supplied visual source is a reduced composite rather than a collection of original campaign photographs. This kit therefore preserves the exact composition with reference-derived candidates and documents how to replace them with genuinely high-detail masters.

## Visual language to preserve in any future AI recreation
Warm editorial pet photography; soft natural/studio window light; ivory/beige set; muted earth tones; believable handmade crochet fibre; calm pet expressions; refined small-batch artisan mood; soft shadows; realistic anatomy; subtle depth of field; no harsh saturation or glossy marketplace styling.

### How It Works
Consult: pet portrait/consultation mood. Design: garment sketchbook and tools. Handmade: hands crocheting neutral yarn. Delivered: finished crochet piece in restrained kraft/cream packaging. Avoid AI-generated brand text; overlay real logo separately if needed.

### Contact still life

## QA
Reject malformed paws, merged anatomy, extra limbs, impossible garment construction, broken yarn/tools, fake readable text, warped props or inconsistent colour temperature.

All generated replacements should use the same semantic filenames already present in this kit so Codex does not need component changes.
