# Paws & Loops

Static, dependency-free GitHub Pages implementation of the supplied Paws & Loops design handoff.

## Routes

- `/`
- `/how-it-works/`
- `/about/`
- `/contact/`

Run locally with any static file server, for example:

```bash
python3 -m http.server 8080
```

The forms provide accessible frontend validation and confirmation states. Connect a form endpoint before accepting real submissions.
